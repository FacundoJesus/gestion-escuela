## 📝 Sobre el Proyecto

Este es un Trabajo Práctico integrador para la materia **Programación IV** de la **UTN - FR Párana**. 
El proyecto consiste en una aplicación web interactiva orientada a facilitar y digitalizar los procesos administrativos y educativos de una institución escolar.

## 🚀 Características Principales

- **Interfaz Intuitiva:** Diseño limpio y fácil de usar, pensado en la experiencia del usuario final.
- **Gestión Dinámica:** Manipulación del DOM y manejo de eventos para una navegación fluida sin recargar la página.
- **100% Vanilla:** Desarrollado sin frameworks de terceros, utilizando HTML5, CSS3 y JavaScript puro para afianzar los conceptos fundamentales de la web.
- **Responsive:** Adaptable a diferentes tamaños de pantalla.

## 🛠️ Instalación y Uso Local

Si deseás correr este proyecto en tu computadora local:

1. Cloná este repositorio:
   ```bash
   git clone https://github.com/FacundoJesus/gestion-escuela.git
   ```
2. Entrá a la carpeta del proyecto:
   ```bash
   cd gestion-escuela
   ```
3. Abrí el archivo `index.html` en tu navegador web preferido, o utilizá una extensión como *Live Server* en VS Code.
